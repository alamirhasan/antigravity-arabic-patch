# Antigravity Arabic RTL Patch 🌍✨

أداة بسيطة وتلقائية لإصلاح ودعم اتجاه اللغة العربية (**من اليمين لليسار RTL**) في تطبيق **Antigravity**.

---

## 💡 المميزات

- 🧠 **كشف ذكي متعدد اللغات (Bi-directional Smart Weighting):**
  - لا يعتمد على أول حرف أو رمز! بل يحلل نسبة الحروف العربية في كل فقرة، فإذا كانت تمثل 30% أو أكثر تصبح الفقرة من اليمين لليسار.
  - تبقى الجملة عربية سليمة حتى لو بدأت بأرقام، رموز، أو مصطلحات إنجليزية مثل `React` أو `Node.js`.
- 💻 **حماية الأكواد البرمجية (Code Immunity):**
  - كتل الأكواد الكاملة (`pre` و `code` ومحرر Monaco) تظل دائمًا من اليسار لليمين (LTR).
  - الكلمات البرمجية المضمنة في وسط الجملة العربية (Inline Code) تُعزل تلقائيًا لتقرأ باتجاهها البرمجي دون أن تعكس الكلمات المجاورة.
- ⚡ **تحديث فوري (Dynamic Observer):**
  - يعمل مع كل رد جديد للذكاء الاصطناعي في الشات فور ظهوره.
- 🛡️ **آمن:** يقوم بعمل نسخة احتياطية `app.asar.bak` تلقائيًا قبل إجراء أي تعديل.

---

## 🚀 طريقة التثبيت والاستخدام

### الطريقة السريعة (بأمر واحد):

1. تأكد من إغلاق تطبيق **Antigravity**.
2. تأكد من تثبيت [Node.js](https://nodejs.org/) على جهازك.
3. افتح موجه الأوامر (Terminal أو PowerShell) ونفّذ:

```bash
git clone https://github.com/hasanamir123/antigravity-arabic-patch.git
cd antigravity-arabic-patch
node patch.js
```

---

## ⏪ طريقة استعادة الوضع الأصلي (Uninstall)

إذا رغبت في التراجع عن التعديل في أي وقت:
1. توجّه إلى مسار:
   `%LOCALAPPDATA%\Programs\antigravity\resources`
2. احذف `app.asar` واستبدله بملف النسخة الاحتياطية `app.asar.bak` (أعد تسميته إلى `app.asar`).
